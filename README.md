# GenthimDeV — Portfolio

Sitio del portfolio de GenthimDeV. Astro + TypeScript estricto + Tailwind CSS v4, sitio estático, bilingüe (es/en).

## Requisitos
- Node 22.12 o superior
- pnpm (vía corepack: `corepack enable pnpm`)

## Comandos
| Comando | Qué hace |
| --- | --- |
| `pnpm install` | Instala dependencias |
| `pnpm dev` | Servidor de desarrollo |
| `pnpm build` | Genera el sitio estático en `dist/` |
| `pnpm preview` | Sirve el build localmente |
| `pnpm check` | Comprueba tipos y plantillas (`astro check`) |
